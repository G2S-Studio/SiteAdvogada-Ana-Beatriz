# Site — Ana Beatriz da Silva | Advocacia Criminal

Site institucional desenvolvido para a Dra. Ana Beatriz da Silva, advogada criminalista em Itatiba/SP.

🔗 **Site publicado:** https://g2s-studio.github.io/SiteAdvogada-Ana-Beatriz/

## Sobre o projeto

Landing page em HTML, CSS e JavaScript puro — sem frameworks. Desenvolvido pela **G2S Studio**.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — estilos e paleta de cores
- `script.js` — pequenas interações (menu, ano do rodapé)
